Put your background music file here, named:

  now-playing.mp3

It should be a track you have the rights to use (something you made,
or a royalty-free track) — this folder cannot hold a raw copy of a
Spotify or YouTube track, since those platforms don't allow that.

Once the file is here, open js/main.js and update:
  - TRACK_TITLE — the text shown next to the play button
  - TRACK_SRC   — only if you rename the file or move it elsewhere
